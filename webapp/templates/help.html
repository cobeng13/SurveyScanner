Help / Instructions

  1. Print the official form. Use 8.5 × 13 in. paper, one side only, at 100% or Actual Size. Fill in course information and applicable CILO statements before photocopying.
  2. Scan the completed forms. Use portrait orientation, 300 dpi, and one completed questionnaire per page. Keep all four black alignment marks visible. Upload a regular, unlocked PDF of up to {{ limits.max_mb }} MiB and {{ limits.max_pages }} pages.
  3. Create one batch per course or class. Enter all course metadata manually. The applicable CILO count uses the first rows of the form in order.
  4. Verify the extracted responses. Open the original page and the recognition overlay side by side with the machine values. Use Blank / missing where an answer cannot be established. Exclude unreadable or unsuitable pages.
  5. Download your results. Provisional outputs include any unreviewed records that are eligible for export. Finalized results use reviewed included records. The machine CSV and audit files preserve OMRChecker’s original output.
